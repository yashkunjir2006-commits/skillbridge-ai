# 🚀 SkillBridge AI

### AI-Powered Career & Job Readiness Platform

SkillBridge AI is an AI-powered career platform designed to help students and job seekers build better resumes, analyze their skills, prepare for interviews, discover learning resources, and create personalized career paths.

> **Build Skills. Beat the ATS. Get Career-Ready.**

---

## ✨ Features

### 🤖 AI Resume Builder
Create a professional resume based on your education, skills, projects, experience, certifications, and career goals.

### 📊 ATS Resume Analyzer
Analyze your resume and understand how well it performs against Applicant Tracking Systems.

**Includes:**
- ATS score
- Skill extraction
- Keyword analysis
- Missing skills
- Improvement suggestions
- Resume optimization

### 🎯 Skill Gap Analysis
Identify the skills you already have and discover the skills you need for your target career.

### 🗺️ Career Roadmap
Get a structured career path based on your target role, current skills, and learning goals.

### 🎤 AI Mock Interview
Practice technical, HR, and behavioral interviews with AI-generated questions and feedback.

### 📚 AI Learning Hub
Discover relevant learning resources based on your target career and identified skill gaps.

### 💡 Career Recommendations
Receive personalized recommendations for:
- Skills to learn
- Projects to build
- Career paths
- Interview preparation
- Resume improvements
- Learning resources

🚀 Getting Started
Prerequisites
Make sure you have installed:
Node.js
npm
Git
Installation
Clone the repository:
git clone https://github.com/YOUR-USERNAME/skillbridge-ai.git
Navigate to the project:
cd skillbridge-ai
Install dependencies:
npm install
Start the development server:
npm run dev
Open the local development URL shown in your terminal, usually:
http://localhost:5173
🔐 Environment Variables
If the project uses external AI services, create a .env file in the root directory.
Example:
VITE_AI_API_KEY=your_api_key_here
Never commit API keys, passwords, or other secrets to GitHub.
